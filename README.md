# Guess The Number Game

A simple web-based "Guess The Number" game where you try to guess a randomly generated number between 1 and 99. You have 10 attempts to find the correct number.

## Features

- Random number generation between 1 and 99
- User-friendly interface with input validation
- Feedback messages for each guess (too high, too low, correct)
- Attempt counter with a maximum of 10 tries
- Responsive and modern design

## How to Play

1. Enter your guess (a number between 1 and 99) in the input field.
2. Click the "Tebak" button or press Enter.
3. The game will tell you if your guess is too high, too low, or correct.
4. You have 10 attempts to guess the correct number.
